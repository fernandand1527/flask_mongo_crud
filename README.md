## ✨ Características Principales

* **📊 Operaciones CRUD Completas:** Interfaz fluida para Crear, Leer, Actualizar y Eliminar registros de forma dinámica.
* **☁️ Conexión Cloud Segura:** Integración optimizada con clústeres de MongoDB Atlas utilizando variables de entorno y control de DNS.
* **⚡ Arquitectura Limpia:** Estructura modular basada en Flask, separando rutas, lógica de negocio y plantillas HTML.
* **🛡️ Seguridad:** Protección contra vulnerabilidades comunes y manejo de sesiones seguras.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python, Flask, PyMongo / MongoEngine
* **Base de Datos:** MongoDB Atlas (NoSQL)
* **Frontend:** HTML5, CSS3, JavaScript
* **Control de Versiones:** Git & GitHub

---

## 📋 Requisitos Previos

Asegúrate de contar con lo siguiente en tu entorno local antes de comenzar:
* Python (versión 3.9 o superior) instalado.
* Git instalado y configurado.
* Una cuenta activa en [MongoDB Atlas](https://cloud.mongodb.com/).
